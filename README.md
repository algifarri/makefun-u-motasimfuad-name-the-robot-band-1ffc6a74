## The entry

`main.py` writes one funny robot band name plus a few words on its hit song
to `/output/entry.txt` — a single line, under 200 characters:

> The Roomba and the Dust Bunnies — hit single 'Suck It Up, Buttercup' spent six weeks at No. 1, then disappeared under the sofa.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, stdlib-only, no network.
